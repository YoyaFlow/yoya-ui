# 08 — 浏览器专属组件服务端占位与客户端初始化

**What to build:** 图表、虚拟滚动、轮播、弹层、消息、上传、锚点、响应式布局等浏览器专属组件在服务端输出静态结构，hydration 后由既有渲染/事件路径初始化，每类组件可验证"服务端可序列化 + hydrate 后可交互"。

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] 每类浏览器专属组件服务端 HTML 可序列化且为合理静态结构。
- [ ] 虚拟滚动服务端输出确定性初始窗口，hydration 后按真实视口校准/追加，不要求严格一致。
- [ ] 大树/千行表格服务端输出上限与基础链路策略协同。
- [ ] hydration 后图表初始化、轮播、弹层、消息、上传等交互可用。
