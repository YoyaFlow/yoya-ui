# 02 — 组件 ID 与全局计数确定性

**What to build:** 组件内部依赖模块级计数生成 id 的场景（树、分页、标签、菜单、导航栏、下拉、提示、时间范围等）改为确定性来源，服务端并发渲染不串号、同页唯一性保持，输出只依赖请求输入。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 相关组件 id 改为局部递增或基于稳定输入的确定性派生，不使用随机或全局顺序计数。
- [ ] 同输入并发渲染产出相同 HTML（可缓存）。
- [ ] 同页多个实例 id 仍唯一。
- [ ] 覆盖树、分页、标签、菜单、导航栏、下拉、提示、时间范围等实例的测试。
