# 05 — 表单 hydration 值回写与双端校验

**What to build:** 表单控件 hydration 时把 DOM 现值回写进内部快照（覆盖 JS 加载前用户已输入的场景）；服务端可先跑校验并把错误状态烘焙进首屏 HTML，客户端用同一套纯函数规则继续校验，取值两端一致。

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] 输入/文本域/下拉/勾选/单选等控件 hydration 时以 DOM 现值初始化快照。
- [ ] 服务端校验结果（错误文案、错误态）烘焙进首屏 HTML。
- [ ] 校验规则保持纯函数，服务端与客户端复用同一套。
- [ ] 覆盖"JS 加载前已输入"、必填、自定义规则、勾选组等场景测试。
