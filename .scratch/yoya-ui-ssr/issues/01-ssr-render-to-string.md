# 01 — SSR 基础渲染链路（renderToString 服务端入口与客户端全量重建挂载）

**What to build:** 开发者能在 Node 环境把声明式页面渲染成完整 HTML（属性转义、布尔属性、样式快照均正确），首屏状态以最小化形式序列化进页面；浏览器端读取状态后重建同一棵组件树并绑定事件，页面交互立即可用。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 提供 renderToString 服务端入口：输入组件与请求上下文，输出 HTML 与序列化状态；入口为纯函数，不读写模块级可变状态。
- [ ] 状态序列化最小化：只包含客户端恢复所需数据，`</script>` 等边界做安全转义。
- [ ] 客户端挂载流程：读取序列化状态 → 以相同初始状态重建组件树 → 事件绑定可用。
- [ ] vStateNode 与 signals 初始状态的注入与恢复链路打通。
- [ ] 大列表/大树服务端输出有上限策略（首屏窗口，超限回退客户端渲染）。
- [ ] 端到端示例页 + 测试：服务端渲染产物在浏览器端可交互，原有测试全部保持通过。
