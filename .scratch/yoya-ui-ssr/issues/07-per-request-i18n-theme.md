# 07 — i18n 与主题每请求状态注入

**What to build:** 服务端从请求上下文解析 locale 与明暗主题并注入渲染，状态随响应序列化；客户端用同一份值初始化；共享单例不被请求修改，并发请求互不干扰。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 每请求创建独立 i18n 实例并经渲染上下文注入，共享单例不被修改。
- [ ] 服务端从请求上下文解析 locale/主题并随状态序列化；客户端恢复一致。
- [ ] locale 切换只替换引用，不克隆整个语言字典。
- [ ] 并发不同 locale/主题渲染互不干扰，输出只依赖请求输入。
