# 03 — 服务端渲染生命周期与模块级注册表清理

**What to build:** 服务端渲染完成后组件树被统一销毁，模块级注册表（如表单单选框组）不跨请求持有引用；连续多次渲染互不污染、内存不随请求数增长。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 服务端渲染流程提供统一的销毁入口并实际调用组件树清理。
- [ ] 表单单选框等模块级注册表在销毁后无残留引用。
- [ ] 连续 N 次（含并发）渲染后注册表 size 为 0、内存不增长。
- [ ] 请求间不可见任何模块级可变状态（无状态硬保证测试）。
