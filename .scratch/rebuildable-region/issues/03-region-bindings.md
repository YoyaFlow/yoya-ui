# 03 — 绑定归区域：重跑释放并重登记 + 值刷新与结构重建分离

**What to build:** 区域内的函数值绑定归该区域所有；重跑时旧绑定整体失效、新绑定立即生效。谓词为假时只刷新绑定值、不重建结构（输入焦点与滚动位置保留），并记脏等待补重建。

**Blocked by:** 01 — 区域声明与手动重跑, 02 — 重跑的环境自持

**Status:** ready-for-agent

- [ ] 绑定登记记录 owner 节点；区域重跑时解除本区域子树名下的绑定。
- [ ] 重跑后不存在重复绑定（同一属性只有一个绑定在写），旧绑定不再写入已销毁节点。
- [ ] 谓词为假时 `rerun()` 只求值写回绑定，不重建 DOM，输入焦点保留。
- [ ] 谓词为假期间的变化被标记为待重建，谓词恢复后补一次重建。
- [ ] 一轮内同一区域最多重跑一次（去重），重跑期间不得重入。
