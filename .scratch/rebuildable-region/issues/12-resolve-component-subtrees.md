# 12 — 区域发现与绑定释放穿透组件子树

**What to build:** 区域收集、绑定 flush 与释放遍历要能进入「延迟解析的组件子树」（`ComponentNode` 的解析结果），使 `x.child(SomeObjectComponent())` 形态里声明的区域也能被自动触发、其绑定也随区域释放。

**Blocked by:** 04 — vStateNode 接入自动触发

**Status:** done（2026-09-12 补记：实现与测试早已落地，票面状态此前未更新；证据见本目录 STATUS.md）

**背景（评审发现）：** `ComponentNode.children()` 在未解析时返回空数组，而区域收集与绑定遍历走的是 `_children`，因此：

- 组件子节点里声明的区域不会出现在组件的区域列表里 → 谓词永不评估、结构永不重跑，且没有任何事件（静默）；
- 该子树里的函数值绑定既不在区域作用域内，也不会被区域释放。

注意：这类子树里「函数值在首屏直接抛 `binding scope required`」是既有行为，不是本次引入的回归。

- [x] 区域收集能进入普通组件子树（按需解析；嵌套状态组件按边界处理，不向父级透出）。
- [x] 绑定 flush / 释放遍历与区域收集共用同一遍历口径（`childTraversalRoots`）。
- [x] 契约测试覆盖「区域声明在对象组件子节点内」与「嵌套状态组件自成边界」两个场景。
