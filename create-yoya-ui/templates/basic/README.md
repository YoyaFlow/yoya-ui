# yoya-ui 示例项目

基于 [yoya-ui](https://github.com/yoyaflow/yoya-ui) 的快速开始模板，包含：

- 页面壳（vBody，主题 token 自动跟随）
- 按钮与事件（快捷方法返回父节点，事件用回调参数）
- 表单收集与校验（vForm + vFormItem）
- 明暗模式切换（data-yoya-mode）

## 启动

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
npm run preview
```

## 学习资源

- 组件使用说明、表单、主题、SSR 与业务模块组织见 yoya-ui skill（`skills/yoya-ui`）
- 完整 API 见包内类型声明（`types/*.d.ts`）
