# data/ —— 默认数据根（项目级）

数据文件放这儿（CSV / JSON / parquet…），**它跟着项目走**：整个目录拷到另一台机器，数据也在。

- **扫出来的事实**（表结构 / 列类型 / 行数 / 大小）放这里（sidecar）或 `../cache/` —— 跟数据绑在一起；
- **靠人 review 的决策**（字段名 / 角色 / 口径 / 取数逻辑）不放这里，放 `../resources/`；
- 大数据 / 敏感数据可以整目录不进 Git（按需加进 `../.gitignore`），但**口径与逻辑仍在 `../resources/`**。

`orders.csv` 是示例数据，供 `apps/main` 的示例页取数（登记表里写 `roots: ["../data"]`）。
