# VSubMenu Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an accessible `vSubMenu` component that opens nested commands with pointer and keyboard interaction and composes with menus, dropdown menus, and context menus.

**Architecture:** `VSubMenu` is a compound `HtmlElementNode` containing a `VMenuItem` trigger and an absolutely positioned nested `VMenu`. The trigger remains owned by the parent menu's roving-focus model, while the nested menu owns its descendants; scoped event handling prevents nested levels from processing each other's keys. The component owns open/close state, document-level outside closing, focus entry/return, and leaf-selection closing.

**Tech Stack:** Vanilla JavaScript ES modules, Yoya UI `ViewNode` factories, Vitest/jsdom, ESLint, Prettier, Vite.

## Global Constraints

- Reusable components and demos use `function ComponentName(options) { return { render() { return viewNode; } }; }`.
- Demo source panels reuse `ComponentSource`; no duplicate source strings are maintained.
- Page composition passes component objects to `child(...)`.
- Preserve unrelated dirty-worktree changes and selectively stage this task.
- Every production behavior begins with a failing Vitest assertion.
- Existing category navigation changes remain a separate commit from `vSubMenu`.

### Task 2: Add keyboard, pointer, focus, and outside-close behavior

**Files:**

- Modify: `src/components/components.test.js`
- Modify: `src/components/index.js`

**Interfaces:**

- Trigger click toggles the submenu unless disabled.
- `ArrowRight`, `Enter`, or Space on the trigger opens it and focuses the first enabled nested item.
- `ArrowLeft` or Escape inside the nested menu closes it and returns focus to the trigger.
- Nested `ArrowUp`/`ArrowDown` remains owned by the nested `VMenu`.
- Outside click closes; selecting a leaf item closes; disabled submenus cannot open.

- [ ] **Step 4: Write failing keyboard and focus tests**
